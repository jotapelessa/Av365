## ADDED Requirements

### Requirement: Luxury Admin Aesthetic
O sistema SHALL implementar uma interface premium baseada na estética "Luxury Admin" definida no `project.md`, utilizando Glassmorphism e Dark Mode por padrão.

#### Scenario: Visual consistency
- **WHEN** um usuário navega entre diferentes módulos
- **THEN** o design system SHALL manter a consistência de cores (Slate/Indigo), sombras e efeitos de transparência.

### Requirement: Collapsible Sidebar
O sistema SHALL possuir uma barra lateral de navegação colapsável que respeita um offset rígido no conteúdo central.

#### Scenario: Sidebar collapse
- **WHEN** o usuário clica no botão de colapsar
- **THEN** a sidebar SHALL diminuir para exibir apenas ícones, expandindo a área de conteúdo sem sobreposição.
